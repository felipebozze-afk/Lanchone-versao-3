# Lanchonete Dogão e Burgão

O projeto está organizado em duas aplicações independentes:

- `frontend/`: interface React/Vite.
- `backend/`: API Node para autenticação.

Para executar, abra dois terminais:

```bash
cd backend
npm run dev
```

```bash
cd frontend
npm install
npm run dev
```
